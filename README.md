# Antigravity Frosted Theme

为 Google Antigravity 桌面客户端提供壁纸驱动的磨砂玻璃界面。主题会把自定义壁纸铺到窗口底层，再将侧边栏、会话区、输入框、弹窗和标题栏统一为半透明玻璃材质；浅色和深色外观会跟随 Antigravity 自动切换。

## 功能

- 全窗口壁纸：支持 JPG、PNG、WebP、GIF，支持点击选择或拖放到预览区。
- 实时材质调节：玻璃浓度、磨砂模糊、色彩饱和、壁纸压暗四项参数均可拖动预览。
- 参数恢复：一键恢复四项材质参数的推荐默认值，或单独恢复默认壁纸。
- 自动保存：滑块和开关修改会延迟保存，点击关闭面板或热重载前也会主动写入，避免丢失最近修改。
- 跨重启持久化：优先使用 Antigravity 原生应用存储，并以 IndexedDB 作为回退，壁纸和参数不会因内部端口变化而丢失。
- 浅色/深色同步：Antigravity 切换外观后，壁纸压暗和玻璃色调会即时刷新。
- 键盘友好：支持 `Alt + F` 呼出面板、`Esc` 关闭面板，并提供完整的焦点样式和焦点循环。
- 响应式设置面板：适配窄窗口，不产生横向滚动；不支持 `backdrop-filter` 的环境会自动使用不透明回退样式。
- 安全回滚：补丁脚本会保留 `app.asar.bak`，可随时恢复官方界面。

## 环境要求

- Windows 10 或更高版本
- 已安装 Google Antigravity 桌面客户端
- Node.js 18 或更高版本

## 快速使用

在项目目录打开 PowerShell：

```powershell
cd D:\项目文件夹\antigravity_theme
npm install
npm run build
```

### 启用主题

关闭 Antigravity 后执行：

```powershell
npm run patch
```

补丁只需执行一次。之后每次启动 Antigravity，主题都会自动加载。主题文件位于项目的 `dist` 目录，因此修改主题后重新执行 `npm run build`，重启客户端即可使用最新版本。

### 立即注入当前窗口

Antigravity 正在运行时，可免重启预览最新构建：

```powershell
npm run inject
```

也可以使用：

```powershell
npm run dev
```

该命令会先构建，再尝试注入当前运行中的 Antigravity 窗口。

### 恢复官方界面

关闭 Antigravity 后执行：

```powershell
npm run unpatch
```

脚本会使用补丁时生成的 `app.asar.bak` 恢复原始客户端。之后如需重新使用主题，再执行一次 `npm run patch`。

## 使用面板

点击右下角的圆形主题按钮，或按 `Alt + F` 打开设置面板。

| 控件 | 用途 |
| --- | --- |
| 启用 | 开关整个磨砂主题，修改立即生效 |
| 壁纸预览 | 点击选择图片，也可以把图片拖放到预览区域 |
| 玻璃浓度 | 调整界面底色的透明程度 |
| 磨砂模糊 | 调整背景虚化范围 |
| 色彩饱和 | 调整壁纸颜色的鲜艳程度 |
| 壁纸压暗 | 增加遮罩，改善文字可读性 |
| 恢复默认参数 | 只恢复四项材质参数，不改变当前壁纸 |
| 恢复默认 | 删除自定义壁纸，恢复内置壁纸；材质参数保持不变 |
| 保存更改 | 立即写入当前状态；通常不需要手动点击，因为修改会自动保存 |

支持的图片格式为 JPG、PNG、WebP、GIF，单张图片不超过 12 MB。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| `Alt + F` | 打开或关闭磨砂主题面板 |
| `Esc` | 关闭已打开的面板 |
| `Tab` / `Shift + Tab` | 在面板控件之间移动焦点 |

## 数据与隐私

主题只保存壁纸和材质参数，不上传图片，也不需要联网服务。配置优先写入 Antigravity 的原生应用存储；当原生接口不可用时，自动回退到浏览器 IndexedDB。点击面板右上角的存储说明按钮，可以查看当前保存策略。

## 常见问题

### 启动后没有出现主题

确认 Antigravity 已完全退出，再运行 `npm run patch`。如果客户端刚完成自动更新，建议重新执行一次补丁，让补丁基于当前版本重新生成备份。

### `npm run inject` 提示找不到窗口

确认 Antigravity 正在运行，并且使用的是桌面客户端窗口。若客户端以管理员权限运行，请用相同权限打开 PowerShell。

### 图片无法保存

请确认图片格式受支持且不超过 12 MB。若仍然失败，关闭 Antigravity 后重新打开；主题会优先从原生存储恢复，必要时从 IndexedDB 读取备份。

### 想彻底移除主题

关闭 Antigravity，运行 `npm run unpatch`，再删除本项目目录即可。补丁不会修改主题目录之外的用户文件。

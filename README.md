# Antigravity Frosted Window Theme (磨砂玻璃窗口高仿套件)

> 本项目对开源项目 [SenryLee/dsh-frosted-window](https://github.com/SenryLee/dsh-frosted-window) 进行了**1:1 高保真复刻与适配**，专为 **Google Antigravity** 桌面客户端打造。选一张图铺满整个窗口，界面以半透明磨砂叠上去，浅色/深色仍跟随官方外观。每次启动 Antigravity 客户端时都会自动加载并应用美化效果。

## 1.2.0 更新

- 重构设置面板的视觉层级：以壁纸预览作为主视觉，合并标题、保存状态、配置入口与关闭操作，减少嵌套卡片和装饰性留白。
- 浅色与深色外观统一采用中性磨砂材质和克制的绿色强调色，滑块、开关、按钮和焦点态保持一致的对比度与反馈。
- 预览区的“玻璃效果”标签改为带底色、边框和轻微模糊的识别芯片；右下角快捷入口改为图标按钮，并保留延迟提示。
- 设置面板适配 320 / 375 / 414 / 768px 窗口宽度，移动端不产生横向滚动，窄屏下控制项自动收为单列。

## 1.1.0 更新

- 热注入前自动清理旧面板、观察器和快捷键监听，避免重复挂载。
- 滑块调节只保存参数；更换壁纸时才写入图片，减少大图重复写盘。
- 删除壁纸改为仅恢复默认壁纸，不再重置当前玻璃参数。
- 设置面板补充键盘焦点循环、状态提示、图片格式校验和窄窗口响应式布局。

## ✨ 核心特性

- 🔮 **1:1 高仿 dsh-frosted-window 磨砂控制面板**
  - **专注单面板磨砂卡片**：去除多余摆设菜单，重构为通透毛玻璃卡片（`#fw-modal-window`），四周为深度景深散景虚化，壁纸柔和透视。
  - **Hero 预览卡片**：展示当前壁纸缩略图与尺寸信息，右下角内嵌实时磨砂玻璃徽章（Frosted Glass Badge），支持**点击选择图片**与**直接拖放图片更换**。
  - **2×2 调节滑块网格**：
    - **玻璃浓度 (Glass Opacity)**：`18%` - `82%` 连续可调。
    - **磨砂模糊 (Blur)**：`8px` - `64px` 动态高斯模糊。
    - **色彩饱和 (Saturate)**：`100%` - `200%`。
    - **壁纸压暗 (Dim)**：`0%` - `65%`，自适应保证文字阅读清晰。
  - **实时响应 (Live Dragging)**：拖动任一滑块时，窗口界面与 CSS 变量毫秒级实时动态变换，防抖自动保存。
  - **状态同步**：支持“已保存”与“未保存”状态指示标签、未保存修改提示、一键“保存”与“删除”恢复默认壁纸。
  - **呼出方式**：右下角悬浮晶体气泡 `🔮 磨砂主题 (Alt+F)` 或直接按下快捷键 `Alt + F` 随时唤出/隐藏，支持 `Esc` 退出；同时在 Antigravity 官方原生设置中无缝植入“磨砂主题”选项。

- 🖼️ **全屏毛玻璃与三大视觉融合**
  - **顶部系统标题栏 100% 融合**：采用原生 `setTitleBarOverlay({ color: '#00000000', height: 30 })`，右上角最小化、最大化、关闭按钮完全透明融入毛玻璃标题栏，彻底消除灰色突兀色块。
  - **侧边栏与会话面板参数对齐**：统一侧边栏与主会话面板的毛玻璃浓度、模糊度与亚克力反光，两者之间设置专属 8px 纯净壁纸透光过渡缝隙。
  - **浮雕发光输入框**：为底部会话输入框重构半透明磨砂胶囊底色，辅以立体边缘高亮微光，既与主会话面板清晰区分，又保持通透质感。
  - **弹窗与下拉菜单全玻璃化**：包括原生设置窗口、快捷菜单、气泡提示等，全部继承毛玻璃背景与磨砂侧边栏。

- 💾 **跨重启数据永久持久化（双引擎保障）**
  - 针对 Antigravity 每次重启随机分配内部 Web 服务端口（导致普通 `localStorage` / `IndexedDB` 隔离失效）的特性，采用 **Antigravity 官方底层 `window.nativeStorage` 原生磁盘持久化引擎**，配置与壁纸数据直接写入系统物理磁盘文件 `%APPDATA%\Antigravity\app_storage.json`。
  - 辅助以 IndexedDB 双向同步与自动迁移机制，彻底保证无论客户端如何重启、关机、随机换端口，自定义壁纸与 4 项滑块参数均永不丢失！

- 🚀 **开机自启动与零二次侵入设计**
  - 通过 `npm run patch` 一键将加载桥接植入 Antigravity 主进程生命周期（`app.asar`）。
  - **仅需打一次补丁**：客户端每次启动时动态加载本项目 `dist/theme.css` 与 `dist/theme.js`。后续在本项目修改样式或脚本，**无需重复打补丁**，重启或刷新客户端即刻生效。
  - 自动备份原始文件为 `app.asar.bak`，支持 `npm run unpatch` 秒级恢复官方原版。
  - 支持 `npm run inject` 免重启实时热推到运行中的客户端。

## 🛠️ 快速使用指南

### 1. 编译构建主题包
在项目根目录运行编译命令：
```bash
npm run build
```
将在 `dist/` 目录下生成 `theme.css` 与 `theme.js`。

### 2. 注入开机自启动补丁（仅需一次）
运行自动化补丁脚本：
```bash
npm run patch
```
- 自动检测并备份原始客户端核心文件为 `app.asar.bak`。
- 将动态桥接挂载至客户端窗口生命周期 `did-finish-load`。
- **完成之后，每次启动 Antigravity 客户端都会自动美化！**

### 3. 免重启实时体验 / 调试
如果 Antigravity 客户端正在运行，直接运行：
```bash
npm run inject
# 或 npm run dev
```
最新样式与脚本将瞬间注入当前窗口，无需关闭或重启客户端。

### 4. 一键恢复官方原版
若需要恢复官方默认无磨砂纯色界面，运行：
```bash
npm run unpatch
```
将立即将 `app.asar.bak` 原样还原，不留任何痕迹。
